01 / IMPORT DES DONNÉES

Connecter ton historique

Importe le fichier data.json ou matches.csv créé par ton analyseur de replays. NEXUS affichera les chiffres reconnus.

🔒 Tes fichiers restent dans ton navigateur. Aucun identifiant Epic n'est demandé.
02 / SOURCE DES REPLAYS

Comment récupérer les données ?

  1. Active Paramètres → Jeu → Rediffusions → Enregistrer les rediffusions dans Fortnite.
  2. Un analyseur compatible lit les replays après chaque partie et produit un historique.
  3. Importe son fichier data.json ou matches.csv ici.

Les fichiers .replay bruts ne sont pas encore décodés directement par cette page. L'analyseur doit d'abord les convertir en statistiques.

Consulter le projet open source ChestCounter ↗
